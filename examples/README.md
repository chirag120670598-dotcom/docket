# Captured output

Real output from this build, not illustrations. Dates are absolute, so these
files stay meaningful as a record even after the site has moved on.

| file | command |
|---|---|
| `01-deadlines-eu-software.txt` | `docket deadlines --market EU --product software --size small` |
| `02-clock-incident.txt` | `docket clock --path incident --aware "5h ago"` |
| `03-route-cascade.txt` | `docket route` with five different fact patterns |
| `04-dossier-vulnerability-notification.md` | `docket dossier --markdown` |

The dossier in `04` is built from a **fictional** product, so that the shape of a
complete Article 14(2)(b) notification is visible without exposing anyone's
incident. Every field is labelled with the limb of the provision it satisfies.
